# 全國大學生二手物品交換與買賣平台 (UniSwap AI)
### Vibe Coding 功能規劃與進階作業整合版

> 專為全國大專院校學生設計的智慧二手循環經濟市集，整合 **4 大 AI 輔助功能**、**校園萌寵伴讀吉祥物** 與 **冒險遊戲化減碳系統**。

## 🚀 快速啟動與免安裝說明 (Zero Setup)

本專案採用現代純前端架構（HTML5、ES6 Modules、Tailwind CSS、LocalStorage 狀態引擎），**完全免裝 Node.js、Python 或任何 npm 套件**。

### 啟動方式：
1. **直接雙擊** 資料夾中的 `index.html` 即可在瀏覽器（Edge / Chrome）中開啟運作。
2. 點擊 `test.html` 執行 **31 項單元與整合測試**。
3. 點擊 `test-isolated-100.html` 執行 **100 組正常、邊界、錯誤與安全隔離測試**。

## 二、安全性稽核與漏洞修復結果 (Security Audit)

在本次驗證過程中，我們針對潛在的安全性漏洞進行了徹底排查與加固：

1. **XSS 跨站腳本攻擊防禦 (已修復加固)**：
   - **檢測發現**：原先商品標題、詳細說明與公開問答若包含 HTML 標籤（如 `<script>` 或 `<img onerror=...>`），直接渲染至 `innerHTML` 會引發 Stored XSS。
   - **處置**：建立 `js/security.js` 模組，所有渲染欄位強制執行 `Security.escapeHtml()` Entity 跳脫，合成測試案例 #86、#87、#88 全數中和驗證通過。
2. **PII 個人隱私資料洩漏防護 (已實作加固)**：
   - **檢測發現**：學生在公開留言區若不慎寫下手機號碼、LINE 帳號，會造成個資外洩與騷擾。
   - **處置**：實作 `Security.checkPiiLeakage()`，能精準捕捉臺灣手機格式（`09xx-xxx-xxx`、`09xxxxxxxx`、`+886 912345678`）與 LINE 帳號，即時攔截並提示警語，合成測試案例 #89~#93 全數通過。
3. **校園信箱嚴格驗證 (已修復加固)**：
   - **檢測發現**：若僅檢查字串是否包含 "edu.tw"，可能被攻擊者以 `user@ntu.edu.tw.attacker.com` 進行子網域偽造繞過。
   - **處置**：改用嚴格正規表達式 `/^[a-zA-Z0-9._%+-]+@[a-zA-Z0-9.-]+\.edu\.tw$/`，精確鎖定 `.edu.tw` 結尾，合成測試案例 #65~#68、#100 驗證通過。
4. **狀態機越權操作防護 (已實作加固)**：
   - **檢測發現**：一般訪客若呼叫狀態切換，可能擅自將他人商品下架。
   - **處置**：實作 `Security.validateStatusTransition()` 狀態機檢驗，限制僅賣家與管理員可切換，且「交易完成」之商品禁止隨意回退，合成測試案例 #94~#98 全數通過。

## 四、重跑與清除測試資料方式 (Rerun & Purge Guide)

為確保評審與測試人員能隨時重現與還原，本專案提供雙重重跑與清除機制：

### 1. 介面視覺化一鍵重跑與清除：
- 開啟 **[`test-isolated-100.html`](file:///c:/HOMEWORK1109/test-isolated-100.html)**：
  - 點擊右上角 **「🔄 重新執行測試 (Rerun)」**：立即在獨立沙盒中重新產生並執行 100 組測試。
  - 點擊右上角 **「🧹 清除測試沙盒資料」**：重置沙盒快取，絕不影響正式首頁之資料庫。
- 開啟 **[`test.html`](file:///c:/HOMEWORK1109/test.html)**：
  - 隨時重新整理頁面，自動執行 31 項單元測試。

### 2. 本地儲存 (LocalStorage) 資料重置方式：
- 若在 `index.html` 操作過程中想恢復到最乾淨的種子資料（8件精選二手物與初始角色）：
  - 打開瀏覽器開發者工具 (F12) $\rightarrow$ 點擊 Console 輸入：
    ```javascript
    window.UniApp.resetAllFilters();
    // 或一鍵重置至種子商品：
    import('./js/store.js').then(m => m.Store.resetToSeed());
    ```
  - 或點擊管理員後台右上角清除快取即可。
