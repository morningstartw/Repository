# 全國大學生二手物品交換與買賣平台 (UniSwap AI)
### Vibe Coding 功能規劃與進階作業整合版

> 專為全國大專院校學生設計的智慧二手循環經濟市集，整合 **4 大 AI 輔助功能**、**校園萌寵伴讀吉祥物** 與 **冒險遊戲化減碳系統**。

---

## 🚀 快速啟動與免安裝說明 (Zero Setup)

本專案採用現代純前端架構（HTML5、ES6 Modules、Tailwind CSS、LocalStorage 狀態引擎），**完全免裝 Node.js、Python 或任何 npm 套件**。

### 啟動方式：
1. **直接雙擊** 資料夾中的 `index.html` 即可在瀏覽器（Edge / Chrome）中開啟運作。
2. 或點擊執行 `test.html` 即可進行 **31 項自動化單元與整合測試**。

## 📋 功能清單與作業規範驗收對照

### 1. 入門功能 (1 ~ 10)
- [x] **1. 商品卡片列表**：顯示圖片、名稱、價格、交易標籤與學校。
- [x] **2. 商品詳細頁**：完整彈窗展示描述、新舊、AI 行情估算、面交點與賣家評級。
- [x] **3. 商品分類**：提供 📚課本教材、💻3C電子、🛋️家具生活、👗服飾配件 等膠囊分類。
- [x] **4. 關鍵字搜尋**：支援即時模糊搜尋，無結果時展示友善 Empty State。
- [x] **5. 價格範圍篩選**：最低與最高金額篩選，具備自動對調防呆。
- [x] **6. 學校與地區篩選**：下拉選單切換學校，支援「同校面交優先」開關。
- [x] **7. 商品排序**：最新上架、價格低到高、價格高到低、同校優先。
- [x] **8. 交易方式標籤**：買賣、以物易物/交換、免費贈送。
- [x] **9. 收藏清單**：點擊 ❤️ 即時加入/取消收藏，跨頁持久儲存。
- [x] **10. 手機版介面**：底部導覽列與觸控友善大按鈕，完全響應式 RWD。

### 2. 中階功能 (11 ~ 20)
- [x] **11. 會員註冊與登入**：支援 .edu.tw 學生信箱驗證。
- [x] **12. 個人檔案與賣場**：個人中心展示暱稱、校園驗證標記、上架商品與星級評價。
- [x] **13. 商品上架與照片**：表單驗證、必填檢查、預覽照片。
- [x] **14. 商品狀態追蹤**：一鍵切換【上架中】、【已預約】、【交易完成】或下架。
- [x] **15. 交換意願設定**：填寫換物心願（如：想換線性代數）與補差價設定。
- [x] **16. 商品公開問答**：公開問答留言板，具備手機個資過濾防護。
- [x] **17. 交易紀錄**：追蹤買賣與交換進度。
- [x] **18. 站內通知**：點擊 🔔 查看最新出價、洽詢與狀態通知，標記已讀。
- [x] **19. 檢舉與管理員後台**：點擊 🛡️ 審核爭議檢舉案件，一鍵下架違規商品。
- [x] **20. 校園身分驗證**：檢查 .edu.tw 格式，顯示學生認證勾號。

### 3. AI 智慧功能 (1 ~ 4)
- [x] **21. AI 拍照自動上架**：點擊「AI 拍照辨識」，模擬多模態分析並一鍵自動代入商品標題、分類與定價。
- [x] **22. AI 二手價格建議**：依據折舊模型計算合理的售價區間，標註「✨ 系統估算值，僅供參考」。
- [x] **23. AI 個人化推薦**：依據使用者科系與收藏，加權推薦最相符商品。
- [x] **24. AI 購物問答助手**：輸入「找 3000 元以下二手平板」，AI 自然語言解析預算與分類並過濾。

### 4. 萌寵吉祥物與遊戲化系統 (特色亮點)
- [x] **25. 五大校園萌寵吉祥物**：🐶 臺大汪、🐱 師大貓、🦦 交大水獺、🦫 成大水豚、🐿️ 中央松鼠。
- [x] **26. 減碳經驗值與冒險等級**：完成交易累積 EXP 與減碳公斤數，升級解鎖稱號。
- [x] **27. 成就勳章牆**：【原文書守護者】、【零元佛心仙人】、【信箱認證學霸】等徽章。
- [x] **28. 每日校園盲盒抽卡**：每日翻開幸運好物盲盒，獲得經驗值與好物推薦。
